# Support

Use GitHub Issues for reproducible bugs and feature requests. Before opening
an issue, check the README limitations and confirm that the lamp is reachable
through Home Assistant Bluetooth or an ESPHome Bluetooth proxy.

Please include:

- integration version and Home Assistant/Python versions;
- lamp model and firmware version;
- Bluetooth adapter or proxy details;
- relevant Home Assistant logs with credentials and mesh data removed; and
- whether the issue affects setup, discovery, or a specific light command.

Never post Oasis passwords, credential exports, mesh keys, account tokens,
sequence databases, or unredacted Bluetooth captures. For security issues,
contact the maintainer privately rather than opening a public issue.

This project is maintained by volunteers and does not promise a response time.
